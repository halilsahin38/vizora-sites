| `diensten.html` | Websites, social media, marketing |

| `contact.html` | Gratis gesprek plannen (via WhatsApp of e-mail) |
| `assets/style.css` | Design: beige, gelaagd, animaties |
| `assets/main.js` | Menu, parallax, tekstanimaties, afsprakenplanner |
